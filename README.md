# תיאור הפרויקט

מנהל משחק מחשב של דילר. המחשב הוא הדילר, והשחקן משחק נגדו.

## חוקי המשחק

**דילר**

1. הדילר משחק שני, אחרי השחקן.
2. הדילר ממשיך לקחת קלפים עד שהוא מגיע למספר 17 ומעלה.
3. אם הדילר עבר את המספר 21, הדילר נשרף והשחקן מנצח.
4. אם הדילר לא נשרף, מי שבידו יש מספר רב יותר של נקודות, הוא זה שמנצח.

**שחקן**

1. השחקן משחק ראשון.
2. השחקן יכול לקחת כמה קלפים שהוא רוצה, ולעצור כשהוא רוצה.
3. אם הסכום שביד השחקן עולה על 21, השחקן נשרף, הדילר ניצח והמשחק נגמר.

**חוקי החישוב**

1. 2-10 = לפי המספר הרשום עליהם.
2. נסיך, מלכה, מלך = J,Q,K = 10.
3. 1 = A = 11/1, תלוי מה עדיף לבעל הקלפים.

**מהלך המשחק**

0. השחקן מניח את ההימור בקופסה.
1. השחקן מקבל 2 קלפים והדילר מקבל שני קלפים
2. שני הקלפים של השחקן גלויים, ואצל הדילר קלף אחד גלוי וקלף אחד הפוך
3. תור השחקן - השחקן מקבל החלטה אם לקחת עוד קלף.
4. השחקן יכול לקחת עוד ועוד קלפים כרצונו ולעצור כשייראה לו.
5. אם השחקן עבר את המספר 21, הוא נשרף והדילר ניצח..
6. תור הדילר - הדילר מושך קלפים עד שהוא מגיע לפחות ל17.
7. אם הדילר עבר את המספר 21, הדילר נשרף והשחקן ניצח.
8. אם הדילר לא נשרף - עושים השוואה. מי שהמספר שלו יותר גבוה הוא מנצח.
9. מי שמנצח מקבל את כל הקופה. אם השחקן מנצח, הוא מקבל את הסכום הכפול שבקופה. אם הוא מפסיד, הסכום הולך לדילר.

## ישויות

### player

| מפתח       | אילוץ                |
| ---------- | -------------------- |
| id         | str                  |
| chips      | int > 0 default=1000 |
| created_at | TimeStamp            |

---

### round

| מפתח        | אילוץ                                                                               |
| ----------- | ----------------------------------------------------------------------------------- |
| id          | string                                                                              |
| playerId    | מזהה של Player קיים                                                                 |
| bet         | int > 0                                                                             |
| playerCards | [ { rank: enum(2..10 , J , Q , K , A), suit: enum(hearts,diamonds,clubs,spades) } ] |
| dealerCards | [ { rank: enum(...), suit: enum(...) } ]                                            |
| status      | enum(in_progress , player_bust , dealer_bust , player_win , dealer_win , push)      |
| createdAt   | datetime                                                                            |

---

## endpoints

| method | url          | header      | body  | goal                                                             |
| ------ | ------------ | ----------- | ----- | ---------------------------------------------------------------- |
| POST   | /start-game  | empty       | empty | יצירת שחקן עם 1000 צ'יפים ושמירה שלו בlocalstorage               |
| POST   | /start-round | x-player-id | {bet} | פותח round חדש במידה ואין אחד פתוח                               |
| POST   | /hit         | x-player-id | empty | שליפת קלף נוסף, חישוב ערך היד, והחלטה אם השחקן נשרף והפסיד       |
| POST   | /stand       | x-player-id | empty | שחקן עוצר. הדילר שולף קלפים, קביעה מי ניצח, ועדכון הצ'יפים בהתאם |
| GET    | /my-round    | x-player-id | empty | מחזיר סבב קיים - status:in-progress                              |

---

## דוגמת ריצה

1. בדיקה אם קיים כבר שחקן. אם אין - ליצור עם /start-game
2. בדיקה אם כבר קיים סיבוב לשחקן. אם כן = המשך משחק - /my-round
3. אם אין משחק קיים - הצגת כפתור "התחל סבב" עם מקום לכתוב בו את גובה ההימור. - /strat-round
4. הצגת מסך המשחק. עם קלפי השחקן, קלף אחד של הדילר וקלף הפוך של הדילר, וכפתורי hit stand.
5. כשנגמר המשחק, הצגת כל קלפי הדילר, הצגת התוצאה, עדכון הצ'יפים, והצעה להתחיל סבב חדש - /start-round
